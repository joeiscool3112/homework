1. Phân biệt sự khác nhau giữa Node.js và JavaScript trên trình duyệt.
- Node.js KHÔNG phải là một ngôn ngữ mới.
- Nó là một runtime environment (môi trường thực thi) cho phép chạy JavaScript ở phía Server.
- JS trên trình duyệt (Browser): thao tác DOM (document, window), UI.
- JS trên Node.js: thao tác File System (fs), Network (http), Database.
2. API là gì? REST API là gì? Giải thích cho người không biết IT hiểu.
- API (Application Programming Interface): Cầu nối giao tiếp giữa Client (React) và Server (Node.js).

- REST (Representational State Transfer): Một bộ quy chuẩn phổ biến để thiết kế API bao gồm, get lấy dữ liệu, post tạo mới dữ liệu, put cập nhật dữ liệu, delete xóa dữ liệu.

3. Trình bày điểm khác nhau giữa HTTP Method GET và POST. Khi nào nên dùng cái nào?
- get để dùng khi ta cần lấy dữ liệu từ server suống client
- post là khi ta cần tạo mới dữ liệu lên server

4. Liệt kê các HTTP Status Code và ý nghĩa của chúng (ít nhất là 200, 201, 400, 404, 500).
- 200: ok thành công
- 201: created tạo mới thành công
- 400: bad request
- 404: not found
- 500: internal server error


5. req.params, req.query, và req.body khác nhau ở chỗ nào trong Express? Xin ví dụ URL đi kèm.
- req.params lấy url từ path
vd: http://localhost:3000/products/1 (1 là params)

- req.query lấy từ sau dấu ?
vd: http://localhost:3000/products?category=Electronics&price=1000
 category là query

- req.body lấy từ body
vd:http://localhost:3000/products
Body: { "name": "iPad Pro", "price": 800 }  ← ẩn, không thấy trên URL
