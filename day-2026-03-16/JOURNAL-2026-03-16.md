## So sánh React vs Vanilla JS
- Vanilla JS: JavaScript thuần, tự thao tác trực tiếp với DOM và xử lý sự kiện
- React: thư viện giúp xây giao diện bằng component và cập nhật UI theo state
- Cái nào dễ hơn cho app phức tạp? Tại sao?
- app nhỏ, Vanilla JS dễ bắt đầu hơn vì không cần học thêm nhiều khái niệm
- app phức tạp, React dễ hơn vì code rõ cấu trúc, dễ chia nhỏ và tái sử dụng
